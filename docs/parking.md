# Known UI issue

## Returned content border / frame styling

- Status: known visual issue; not a Public Alpha v0.1 blocker.
- Current behavior: returned content may display a border or frame.
- Preferred outcome: no border, or a more natural presentation.
- Revisit only if an official image-capable Return route becomes available or the isolated Experimental Return research is intentionally resumed.

This issue affects the presentation of returned content only. It does not change the current decision to park official image Return or the separation of the Experimental Return PoC.
