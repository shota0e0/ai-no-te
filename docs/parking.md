# Known UI issue

## Returned content border / frame styling

- Status: known visual issue; not a Public Alpha v0.1 blocker.
- Current behavior: returned content may display a border or frame.
- Preferred outcome: no border, or a more natural presentation.
- Revisit after the public Experimental Desktop Return receives fresh visual evidence, or if an official image-capable route becomes available.

This issue affects presentation only. It does not change the decision to keep official image Return parked or the separate Experimental Desktop compatibility boundary.

## Additional Desktop page models

- Status: future compatibility work; not a blocker for the supported A2 image-page path.
- Current behavior: Experimental Desktop Input fails closed when a page has no unambiguous full-page image, handwriting-layer set, or single image attachment.
- Preferred outcome: add a page model only after its resource relationship and read-only behavior are verified with reproducible evidence.

The runtime does not guess another note, page, or resource when it encounters an unsupported Desktop structure.
