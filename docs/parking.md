# Known UI issue

## Returned content border / frame styling

- Status: known visual issue; not a Public Alpha v0.1 blocker.
- Current behavior: returned content may display a border or frame.
- Preferred outcome: no border, or a more natural presentation.
- Revisit after the public Experimental Desktop Return receives fresh visual evidence, or if an official image-capable route becomes available.

This issue affects presentation only. It does not change the decision to keep official image Return parked or the separate Experimental Desktop compatibility boundary.
